# PMI — Partido Inter Mundos

Portal institucional do movimento cívico em formação **PMI | Lovi**.

Este projeto não representa um partido oficialmente registrado nem anuncia candidatura. O convite a participar **não equivale a filiação partidária legal**.

## Conteúdo
- Paz, diálogo e educação cívica;
- Análises técnicas e verificáveis de propostas públicas;
- Missão, valores e participação voluntária;
- Seção 'Precisamos de Vocês' — escuta aberta a todas as comunidades.

## Publicação
Site estático: `index.html` e `participar.html`. Pode ser publicado na Hostinger Business ou GitHub Pages. Formulário demonstrativo: não registra dados pessoais até integração de backend seguro.
